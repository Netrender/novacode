**NovaCode IDE** — это полноценная десктопная среда разработки, созданная с нуля на современном стеке технологий.
Она объединяет мощь **Monaco Editor** (движок VS Code), **встроенный ИИ-ассистент** с поддержкой любых нейросетей,
**живой предпросмотр** веб-страниц, **терминал**, **Git-панель** и **SQL-просмотрщик** — всё в одном элегантном интерфейсе.

> 💡 *Вам не нужен ключ от конкретного провайдера. NovaCode работает с любым API — от OpenAI и Claude до локальной Ollama на вашем компьютере.*

## 💎 Почему NovaCode?

Большинство IDE либо перегружены функциями и потребляют гигабайты оперативной памяти, либо слишком примитивны для серьёзной работы. NovaCode занимает золотую середину:

| Проблема | Решение в NovaCode |
|---|---|
| 🧠 ИИ-ассистенты привязаны к одному провайдеру | Универсальный протокол: работает с **любым** API (OpenAI, Anthropic, OpenRouter, DeepSeek, Ollama, LM Studio) |
| 💰 Платные подписки за встроенный ИИ | Используйте **свой ключ** от любого провайдера — никаких скрытых комиссий |
| 🔄 Предпросмотр требует отдельного браузера | **Live Preview** прямо внутри IDE с адаптивными режимами (Desktop/Tablet/Mobile) |
| 📦 Сложная установка и настройка | **Один .exe файл** — установщик или портативная версия без инсталляции |
| 🏗️ Закрытый исходный код | **Полностью открытый** исходный код (MIT лицензия) |

### Ключевые функции ИИ

| Функция | Описание |
|---------|----------|
| 🌊 **Потоковый вывод** | Ответы появляются в реальном времени по мере генерации, а не ожидание полного ответа |

## 📝 Редактор кода

Сердце NovaCode — это **Monaco Editor**, тот самый движок, на котором построен Visual Studio Code.

### Возможности редактора

- 🎨 **Подсветка синтаксиса** для 90+ языков программирования (JavaScript, TypeScript, Python, Rust, Go, C++, Java, Kotlin, Swift, PHP, Ruby, SQL и многих других)
- 🧠 **IntelliSense & Автодополнение** — контекстные подсказки по коду, параметрам функций и свойствам объектов
- ⚡ **Emmet** — мгновенное развёртывание HTML/CSS аббревиатур (`div.container>ul>li*5` → полный HTML за один Tab)
- 📑 **Мульти-табовый интерфейс** — одновременная работа с несколькими файлами, переключение по табам
- 🔍 **Поиск и замена** — с поддержкой регулярных выражений
- 📏 **Мини-карта** — навигация по большим файлам
- ✂️ **Мульти-курсор** — одновременное редактирование нескольких строк
- 🔄 **Автосохранение** — настраиваемое автосохранение открытых файлов
- 📐 **Настраиваемый шрифт** — выбор размера шрифта от 12 до 16px

### Темы оформления

| Тема | Описание |
|------|----------|
| 🌌 **Nova Dark** | Космическая тёмная тема — фирменный стиль NovaCode IDE |
| 🌙 **VS Code Dark** | Классическая тёмная тема, знакомая каждому разработчику |
| ☀️ **Nova Light** | Чистая белая тема для работы при ярком освещении |
| 🌊 **Light Blue** | Светло-голубая контрастная тема |

## 🌐 Живой предпросмотр (Live Preview)

NovaCode включает **встроенный браузер** для мгновенного предпросмотра HTML/CSS/JavaScript проектов без необходимости открывать внешний браузер.

### Возможности
- ⚡ **Мгновенный рендеринг** — изменения в коде отображаются сразу в окне предпросмотра
- 📱 **Адаптивные режимы** — переключение между Desktop, Tablet и Mobile видом
- 🔄 **Автообновление** — предпросмотр автоматически обновляется при изменении кода
- 🖼️ **Встроенный iframe** — изолированная среда рендеринга, безопасная от конфликтов с IDE

## 💻 Интегрированный терминал

Полноценная консоль прямо внутри IDE — не нужно переключаться между окнами.

- 🖥️ **PowerShell / CMD / Bash** — работа с любой оболочкой Windows
- 📋 **Буфер обмена** — полноценная поддержка копирования и вставки текста
- 📜 **История команд** — навигация по предыдущим командам
- 🎨 **Цветной вывод** — ANSI цвета для читаемого вывода логов, сборок и тестов
- 📏 **Ресайз** — изменяемый размер панели терминала

## 🔧 Настройка ИИ-ассистента

### Быстрая настройка (3 шага)

1. **Выберите формат** — OpenAI или Anthropic
2. **Укажите Base URL** и **API Key** вашего провайдера
3. **Введите модель** — любое название (`gpt-4o`, `claude-3-5-sonnet-20241022`, `deepseek-chat`)

### Таблица быстрых настроек

| Провайдер | Формат | Base URL | Пример модели | Бесплатно? |
|-----------|--------|----------|---------------|:---:|
| **OpenAI** | OpenAI | `https://api.openai.com/v1` | `gpt-4o` | ❌ |
| **Anthropic** | Anthropic | `https://api.anthropic.com` | `claude-3-5-sonnet-20241022` | ❌ |
| **OpenRouter** | OpenAI | `https://openrouter.ai/api/v1` | `anthropic/claude-3.5-sonnet` | Частично |
| **DeepSeek** | OpenAI | `https://api.deepseek.com/v1` | `deepseek-chat` | ❌ |
| **Groq** | OpenAI | `https://api.groq.com/openai/v1` | `llama-3.1-70b-versatile` | ✅ |
| **Ollama** | OpenAI | `http://localhost:11434/v1` | `llama3`, `codellama` | ✅ Локально |
| **LM Studio** | OpenAI | `http://localhost:1234/v1` | `local-model` | ✅ Локально |

> 💡 **Совет:** Для бесплатного использования ИИ установите [Ollama](https://ollama.ai/) и скачайте модель: `ollama pull llama3`. Затем укажите в NovaCode Base URL `http://localhost:11434/v1` и модель `llama3`.

## 🛠️ Установка

### Готовые сборки (Windows x64)

| Тип | Файл | Описание |
|-----|------|----------|
| 📦 **Установщик** | `NovaCode-IDE-Setup-1.0.0-beta.exe` | NSIS инсталлятор: выбор папки, ярлыки, деинсталлятор |
| 🚀 **Портативный** | `NovaCode-IDE-Portable-1.0.0-beta.exe` | Один файл, запуск без установки |

### Сборка из исходников

```bash
# 1. Клонировать репозиторий
git clone https://github.com/Netrender/novacode.git
cd novacode

# 2. Установить зависимости
npm install

# 3a. Запуск в браузере (режим разработки)
npm run dev

# 3b. Запуск в Electron (десктоп)
npm run electron:dev

# 4. Сборка релиза (установщик + портативная версия)
npm run electron:build
```

| Диск | 300 МБ | 500 МБ |
| Процессор | 2 ядра | 4+ ядра |
